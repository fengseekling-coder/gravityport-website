WEB CAPTURE / INSTALL GUIDE

四步接好
MOSA Web Capture。

浏览器扩展负责把网页里的 AI 生成结果送进本机 MOSA。正式下载开放后，按照下面的步骤安装即可。

前往下载页 ↗
  1. 01

    下载并解压 ZIP

    下载 MOSA Web Capture ZIP 后，把它解压到一个固定的本地文件夹。不要直接在 ZIP 压缩包里加载扩展。

  2. 02

    打开扩展管理页

    在 Chrome / Chromium 地址栏输入 chrome://extensions，然后打开右上角的“开发者模式”。

  3. 03

    加载完整插件包文件夹

    点击“加载已解压的扩展程序”，选择解压后的插件文件夹。打开后第一层应该能直接看到 manifest.json。

  4. 04

    打开 MOSA 并测试连接

    先启动 MOSA Desktop，再打开扩展选项。扩展会自动发现本机 MOSA 并完成安全配对，用户无需填写地址或 Ingest Token；点击“测试连接”，看到成功提示后即可使用。

ZIP ROOT

确认你选对了目录

被选择的文件夹第一层应该直接看到这些文件：

  • manifest.json扩展入口
  • background.js后台服务
  • options.html设置页
TROUBLESHOOTING

连接不上时先检查

  • MOSA Desktop 是否已经启动。
  • 是否在扩展选项中重新点击了“测试连接”。
  • 扩展更新后，是否在扩展管理页点击了刷新。
  • 仍无法连接时，依次重启 MOSA Desktop 和浏览器。

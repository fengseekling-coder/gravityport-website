隐私政策

GravityPort 是本地素材库：没有账号，没有云端，素材库只在你的电脑上。这一页写清楚它读什么、存什么、什么时候联网。

最后更新 2026-10-21

要点

  • 素材库只在你的电脑上，不上传，不同步。
  • 浏览器扩展只把图片和来源信息发给你电脑上的 GravityPort。
  • 自动联网只有检查更新和每天最多一次的匿名活跃信号，都不含素材、Prompt、文件名或路径。
  • 反馈只在你点「发送」时提交，诊断日志默认不附带。
  • 第三方不卖数据，不做广告画像。

读取的数据

只读你启用的来源：

  • Codex：生成图片的目录，以及对得上的本地 Codex 会话记录，用来补上 Prompt 和来源。
  • Grok Build CLI：~/.grok/sessions 里的图片、视频和对得上的 chat_history.jsonl 记录。
  • Cowart：GravityPort 专用画布，以及最近 14 天里从 Codex 启动过 Cowart 的项目画布。
  • 浏览器扩展发来的图片和来源信息，见「浏览器扩展」。
  • ChatGPT 桌面版的本地状态文件，只读其中的对话编号，见「ChatGPT 桌面版的对话」。

GravityPort 不扫描「下载」「桌面」、无关的项目文件夹，也不读任意网页。

存储的数据

素材库就是你选的那个文件夹，里面有：

  • 原图或视频，以及预览图和缩略图；
  • Prompt 和你说的话；
  • 来源、时间、尺寸、模型或工具、页面地址等来源记录；
  • 版本关系、标签、分组和堆叠；
  • 参考图：作为私有附件和用到它的图存在一起，不出现在画廊、搜索和素材总数里；
  • ChatGPT 桌面版的同步进度 .chatgpt-desktop-sync.json：最多 200 段对话的编号、时间、重试次数和一个哈希值，不含提示词。

素材库不会上传到 GravityPort 的服务器。导出分组时，导出文件只含元数据，不含任何本地路径。

浏览器扩展

  • 只在 ChatGPT、Gemini、Flow、Google AI Studio 的页面上运行。
  • 新装时自动收录默认关闭，并打开设置页，让你看完说明再决定；也可以用右键菜单手动保存。
  • ChatGPT：图片、对应的 Prompt 和你说的话、这一轮上传的参考图、对话和消息编号、这张图是第几轮（只有编号和序号，不含对话正文），以及对话标题（用来给堆叠起名）。
  • Gemini、Flow、Google AI Studio：图片，加上页面上能可靠对上的那一句提问或那张 Prompt 卡片，标为「未核实」。不读输入框、隐藏内容和模型思考。
  • 收到的内容只发给你电脑上的 GravityPort（127.0.0.1 / localhost），不发给任何服务器。
  • 本机地址、配对 Token、自动收录开关和待重试队列存在 chrome.storage.local，不随 Google 账号同步；等待重试的媒体暂存在扩展本地，送达或过期后删除。
  • 不读取、不保存、不发送账号密码、Cookie 和 API Key，也不读取 ChatGPT 的授权请求头。唯一用到 ChatGPT 登录的地方见下一节。
  • 权限：storage、contextMenus、alarms，以及上面这些站点、它们的图片和视频域名、本机地址。不运行远程代码。

ChatGPT 桌面版的对话

ChatGPT 桌面版（现在 Codex 也在这个 App 里）不把聊天里的图存到电脑上。为了收录这些图，GravityPort 这样做：

  1. 开着 Codex 来源时，约每 10 秒读一次桌面版的状态文件 ~/.codex/.codex-global-state.json，只用其中的对话编号和每段对话最后一次提问的编号，不读提示词正文。
  2. 某段对话安静 90 秒后，交给已配对、开着自动收录的扩展，一次一段。
  3. 扩展用浏览器里已登录的 ChatGPT 账号，向 chatgpt.com/api/auth/session 取一次访问令牌，只用来读这一段对话、看里面有没有生成图。令牌不保存，不发给 GravityPort，也不发给 chatgpt.com 以外的任何地方。
  4. 没有图就到此为止；有图时，在一个最小化、不抢焦点的窗口里打开这段对话，像你自己打开一样收录，20 到 110 秒后自动关闭。

这些请求由你的浏览器用你自己的 ChatGPT 登录发出，GravityPort 本身不连接 OpenAI。想停止：关掉扩展的自动收录，或停用扩展。想让 GravityPort 完全不读这个状态文件：用 MOSA_DISABLE_BRIDGES=codex 关掉 Codex 来源，这也会停止导入 Codex 的图。

自动联网

GravityPort 的本地服务只监听 127.0.0.1，不对外开放。桌面版只在下面两种情况自动联网，都发到 mosa.azhuilab.com，都不含素材、Prompt、文件名、路径或账号信息。

检查更新

打开窗口时，如果距上次检查超过 24 小时，或者你手动检查，就读一次更新清单。只有你点「下载并更新」，才下载对应平台的更新包；下载后按大小和 SHA-256 校验，只替换 App 本身，不碰素材库。

匿名活跃信号

按太平洋时间每天最多一次，发一个不带正文的请求，只含：

  • 事件类型（首次启动或每日活跃）和协议版本；
  • 一个随机安装 ID：在你电脑上随机生成，不来自设备序列号、账号、路径或硬件信息；
  • GravityPort 版本、系统类别（macOS / Windows / 其他）和芯片架构（如 arm64、x64）。

App 里没有开关，用环境变量 MOSA_DISABLE_TELEMETRY=1 关闭。关闭后安装 ID 只存在本地，不再发送。

# macOS，只对这一次启动生效
MOSA_DISABLE_TELEMETRY=1 /Applications/GravityPort.app/Contents/MacOS/GravityPort
# macOS，从程序坞或访达打开也生效，直到重启电脑
launchctl setenv MOSA_DISABLE_TELEMETRY 1
# Windows，之后每次启动都生效
setx MOSA_DISABLE_TELEMETRY 1

Windows 上要恢复，在「系统属性 → 环境变量」里删掉它。

App 不下载任何模型。官网的下载链接可能带一个来源标签（如 ref=…），只用来统计下载从哪个页面来，不需要登录。

Pinterest（尚未开放）

可以选择连接你的 Pinterest 账号，在 App 里浏览自己的画板和 Pin。功能已经做好，要等 Pinterest 批准正式接口后才开放；不连接，GravityPort 就不访问 Pinterest。

连接后只读：你的用户名，画板（含私密画板）的名称、描述、Pin 数和封面，以及 Pin 的标题、描述、链接和图片地址。这些只在你电脑上实时显示，不存进素材库，也不上传；内存里最多暂存 5 分钟。

授权令牌只存在你电脑上一个权限受限的文件里。授权时，我们的服务器只把授权码转交 Pinterest 换取令牌、原样返回，不保存，也不记日志。在设置里断开连接，就删除本地令牌；也可以在 Pinterest 账号设置里撤销授权。

反馈

只有你在「设置 → 反馈」里点「发送」，才会提交到 mosa.azhuilab.com/api/feedback，内容是：

  • 你写的正文（最多 5000 字），和你自愿填写的联系方式（只用来回复你）；
  • 反馈类型、界面语言、App 版本、系统和版本、芯片架构；
  • 勾选「附上诊断日志」时（默认不勾），附带最近的运行日志。发送前能看到完整内容；路径里的用户名、令牌和邮箱会被隐藏，可能含提示词的行整行去掉。

不发送安装 ID、素材、提示词和素材库位置。服务器不保存 IP，只在内存里临时用来防止滥用。反馈存在官网服务器的私有目录，只有开发者能看，只用来回复你和改进产品。要删除你发过的反馈，写信到 fengseekling@gmail.com，说明大概的发送时间。

你能控制的

  • 在「设置 → 存储」里把素材库搬到另一个空文件夹。
  • 关掉扩展的自动收录：自动收录和 ChatGPT 桌面版的收录都停止，手动保存还能用。停用或卸载扩展则完全停止。
  • 用 MOSA_DISABLE_BRIDGES 关掉某个来源（codex、grok、cowart）。
  • 用 MOSA_DISABLE_TELEMETRY=1 关掉匿名活跃信号，见「自动联网」。
  • Pinterest 在你连接之前不会被访问，断开连接即删除本地令牌。
  • 删除、移进回收站或归档素材。归档只是整理，不等于安全擦除；系统备份、浏览器数据和各工具自己的历史需要另外清理。

第三方服务

ChatGPT、Gemini、Flow、Google AI Studio、Codex、Grok、Cowart、Chrome 和 Pinterest 都是独立产品，它们自己的联网行为和隐私政策照样适用。

GravityPort 不出售数据，不把数据用于广告画像、信用评估或贷款。

联系与安全

安全漏洞请按 GitHub 仓库里的安全说明报告。其他问题可以在 GitHub Issues 里提，但不要贴 Token、Prompt、私人素材或对话内容。

INSTALL GUIDE

第一次安装，
四步接好 Web Capture。

这是 Chrome / Chromium 的 Manifest V3 开发者模式 ZIP 安装流程，不是 CRX，也不是商店安装。

下载 MOSA Web Capture ZIP

当前包 v0.11.1· Chrome / Chromium

  1. 01

    下载并解压 ZIP

    点击上方按钮下载 MOSA Web Capture ZIP，再把 ZIP 解压到一个容易找到的本地文件夹。

  2. 02

    打开扩展管理页

    在 Chrome / Chromium 地址栏输入 chrome://extensions，打开右上角的“开发者模式”。

  3. 03

    加载完整插件包文件夹

    点击“加载已解压的扩展程序”，选择解压后得到的完整插件包文件夹；打开后第一层应直接看到 manifest.json。不要选择 ZIP 文件、manifest.json 文件本身或外层父文件夹。

  4. 04

    打开选项并测试连接

    在扩展卡片的“详情”里打开“扩展程序选项”，填写本机 MOSA 地址（默认 http://127.0.0.1:43517）和与 MOSA 服务一致的 Ingest Token，保存后点击“测试连接”。

遇到问题先检查

目录和 Token 是关键

  • 不要选择 ZIP 文件本身，也不要选择多一层父目录。看到 manifest.json 文件后，点击选择/打开该文件夹。
  • Token 不要放到公网、截图或 Issue。
  • 测试连接前，先确认本机 MOSA 服务正在运行。
  • 扩展更新后，在 chrome://extensions 点击刷新，再硬刷新网页。

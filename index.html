    SHEET 10 / 12K FLOOD + 802 FLUOOK TO PRINT

    四步装好
    浏览器扩展。

    扩展负责把网页里生成的图送进你电脑上的 GravityPort，需要在 Chrome / Chromium 的开发者模式下加载。

    1. 01

      下载并解压 ZIP

      在上方下载区下载扩展 ZIP，解压到一个固定的文件夹。不要直接从压缩包里加载。

    2. 02

      打开扩展管理页

      在地址栏输入 chrome://extensions，打开右上角的「开发者模式」。

    3. 03

      加载解压后的文件夹

      点「加载已解压的扩展程序」，选中解压出的文件夹。

    4. 04

      打开 GravityPort，测试连接

      先打开桌面版，再打开扩展设置页，扩展会自动找到 GravityPort 并配对。勾上「发现新图时自动入库」，点「保存设置」，再点「测试连接」，提示成功就能用了。

    选对文件夹了吗

    选中的文件夹第一层应该能直接看到这三个文件：

    • manifest.json
    • background.js
    • options.html

    连不上时先检查

    • GravityPort 桌面版已经打开。
    • 在扩展设置页再点一次「测试连接」。
    • 更新扩展后，在扩展管理页点刷新。
    • 仍然不行，就依次重启 GravityPort 和浏览器。

    SHEET 11 / 12K + 802 FLUOWEB CAPTURE · INSTALL

    常见问题

    要注册账号吗？

    不用。GravityPort 没有账号，也没有云端。

    我的图会被传到别的地方吗？

    不会。素材库只在你的电脑上。桌面版自动联网只用于检查更新和每天最多一次的匿名活跃信号，都不含素材、Prompt、文件名或路径。

    电脑里已经有的图，能放进来吗？

    能，拖进窗口就能导入。GravityPort 不会自己扫描「下载」或「桌面」文件夹。

    支持哪些系统？

    Apple 芯片的 Mac，以及 Windows 10/11。

    遇到问题怎么反馈？

    在 App 的「设置 → 反馈」里发送，可以附上已脱敏、发送前能完整查看的诊断日志。也可以 。
